# Connect gets its own repository

First publication of Connect in its own repository. The mod itself has not changed since the previous version: what changed is the address, which is now fixed and only its own — the download link never points at something else when another mod ships.

- **Nothing new in the mod**: Connect 0.1.3 is the same one from the previous bundle.
- **Fixed link**: the `Connect.steinmod` on this page is always the latest Connect, no matter what the other mods release.
- **Needs Stein Loader 0.1.9**: every mod now asks for the Loader released today, so there is no version mix nobody tested. With an older one, the mod shows up in the list with the reason written out.
