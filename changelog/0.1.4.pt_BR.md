# Connect com repositório próprio

Primeira publicação do Connect no repositório dele. O mod não mudou desde a versão anterior: o que muda é o endereço, que agora é fixo e só dele — o link de download nunca mais aponta para outra coisa quando sai versão de outro mod.

- **Nada novo no mod**: Connect 0.1.3 é o mesmo que já estava no pacote anterior.
- **Link fixo**: o `Connect.steinmod` desta página é sempre a última versão do Connect, independente do que os outros mods lancem.
- **Pede o Stein Loader 0.1.9**: todos os mods passaram a exigir a versão do Loader que sai hoje, para nao haver combinacao de versoes que ninguem testou. Com uma anterior, o mod aparece na lista com o motivo escrito.
