# Connect 0.1.7: contas sem limite

A lista de contas do Connect não tem mais limite e não muda de ordem a cada clique.

- **Contas sem limite**: a lista de nicks offline não para mais em 6 — tem quem use dezenas de contas.
- **A lista fica no lugar**: entrar com uma conta que já está na lista não a joga para o topo; só a conta nova entra no topo.
- Os proxies guardados continuam até 6.
